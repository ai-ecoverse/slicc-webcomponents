# slicc-webcomponents

Empty package for shared web components on Spectrum Web Components. Implementations will later move here from slicc-spectrum and SLICC's `packages/webcomponents`.

```js
import {} from '@ai-ecoverse/slicc-webcomponents';
```

Node ≥ 24. `npm run lint` runs `slicc-lint`. Releases use semantic-release on `main`.
